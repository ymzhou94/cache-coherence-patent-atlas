Trace cache techniques based on biased control transfer instructions

核心结论

预测器按过去的执行方向判定偏向，拼接逻辑只让满足条件的分支留在 trace 内部。训练逻辑并行保留部分重叠的候选，比较效用后让一条成为有效条目。过早退出的低稳定性内部分支还可在随后训练中被屏蔽。

在指令缓存和 trace cache 中，同一个跳转后面是什么

原图 1、4 把普通指令缓存与 trace cache 放在译码输入选择器两侧。原图 2B 进一步限定 trace 内部可接受的取指组。普通指令缓存按地址相邻性保存指令，跳转后面的字节可能是顺序路径。拼接队列则能把预测为跳转的分支与目标取指组连到同一条 trace。

图 1 从指令缓存取出组 A 的跳转和目标组 B。第一项装置权利要求写明，一条候选至少有一条实际采用跳转方向的内部控制转移指令（CTI）。内部条件 CTI 必须满足第一类偏向判定。未达到第一类阈值的第二类 CTI 只能作为末尾 CTI。末尾也可以是普通指令。偏向是对观察窗口的归类，执行流水线仍检查实际结果。

内部分支反复提前退出，怎样阻止再次拼入

图 2 对应第 4 项中第一类的子集。它们达到准入所用的第一阈值，未达到更严格的第二阈值。说明书称在限定位置允许留在 trace 内部的机制为 LBE（less-stable before end）。原图 10A、10B 展开这一步。沿存储路径执行推动效用计数增加，提前退出则推动计数降低。下降幅度可以更大。

原图 11 将 LBE 训练过滤器置于训练电路与 trace cache 之间。计数跌过下阈值的实施方式可清除旧条目的有效位，并以分支 PC 或所在组 PC 更新 Bloom 过滤器，阻止同一分支继续作为新 trace 的内部指令。过滤器可周期清除，之后才有重新参与训练的机会。过滤器误命中会少形成某些可用 trace。

偏向比例与效用阈值各用于哪一环

第 2 项要求在观测时段内一直取同一方向，第 3 项允许达到给定比例。说明书举例用 95%、98% 或 99.5% 定义某些实施的偏向标准，未为全部实现给固定阈值。表 3 分开列出统计定义和用途。

达到偏向门槛可满足内部 CTI 的一项要求。是否真正安装到 trace cache，还要核对其他拼接条件、训练效用与可用表项。评估时分别记录形成候选数、安装数、命中后的完成比例、退出后的重定向，以及基础指令缓存的取指次数。

滚动窗口共享取指组，效用却按候选计算

说明书 [0045] 给出 A–B–C 与 B–C–D，两条候选共享 B、C。图 4 从取指组到窗口移动，再到各候选独立的效用字段。第 1、14、18 项把滚动缓冲和依据效用从重叠候选确认一条写进独立项。

在图示的比较中，两条候选均参与效用选择。说明书允许此前在独立训练缓冲保存指令，也允许暂存在 trace cache 中并保持训练状态，达到阈值后才置为有效。它未指定相同效用时如何选择。第 8 项还限定训练只接受来自指令缓存的取指组，已有 trace 的输出不作为这条训练路径的输入。

trace 未被清除时，如何为下一次提前退出预测顺序 PC

原图 10C 的 trace 后继预测器有两个与此直接相关的字段：预测下一取指地址和 LBE 方向标记。说明书 [0129] 举例，原 trace 假设内部 LBE 分支跳转，第一次实际不跳转时丢弃该分支后的组内指令并重定向。只要效用尚未跌落到失效条件，前端可保留该 trace，将下一取指地址改为这个分支的顺序后继，并置 LBE 标记。

图 5 对比第一次退出和后续重复同方向的退出。标记有效时，预测器可直接给出顺序后继，并避免应用整条 trace 的分支历史更新。LBE 再次取原来的方向时，可以清标记并恢复 trace 末尾目标。第 11 项要求单拍的 trace 后继预测，具体 LBE 目标与历史恢复属于说明书实施例。
