由远端 ECC 事件冻结的发送电压监测

Voltage monitoring circuit for interface

芯粒接口偶发错码时，怎样拿到发送端出错前后的电压，而不连续导出采样流？

工程要点

链路接收端的错误指示送回事件捕获电路，触发保留发送端的供电电压信息。

成立条件
错误通知到达采样端有跨芯粒延迟。时间对齐只能建立相关性。
验证方法
在发送端注入带时间标记的扰动，对照接收端错误、通知返回与波形冻结时刻。检查事件前历史是否仍在留存窗口。

工作机制

链路错误的检测点在接收方，待查的电源扰动却可能在发送方。跨芯粒错误回传形成的延迟决定 FIFO 是否保住之前的样本。

发送侧实时示波模块在调试模式量化发送器电压并维护滚动 FIFO。远端接收器的 ECC 错误回传后触发停止采样和保留数据，主机可读出事件附近的电压序列。

  1. 在发送点不断测量

    本地 ADC 周期采样 Vdd，FIFO 先入先出。新值顶掉较早的样本，为非持续性错误保留一个滑动窗口。

  2. 接收方给出错误标志

    图 3 的接收方用 ECC 判断错误，把标志跨回链路送到发送端 RTO。图 4 展示两方向独立诊断。

  3. 冻结历史

    收到错误指示后 ADC 可停采。检出和回传并非同时发生，停止时 FIFO 可能已含若干错误后的样本。

  4. 主机对照观察

    把存储的值送到外部调试主机。应校正双向链路及 ECC 延迟再把电压异常与错误时间关联。

权项与实施例约束

图 4–6 把采样源放在发送端，把触发源放在接收端。要看到可能导致错码的发送窗口，发送端保留的前触发历史至少须覆盖链路传输、检错和通知返回三段延迟。

图解与对照

  • 从错码检出到导出电压历史
  • 8 项 FIFO 的故障前后时间窗
  • 冻结时哪一段原始波形仍在

工程推演与验证

收益与开销

对照同一错误事件在接收端的计数和发送端留存波形中所在的位置。采样频率决定电压扰动的时域分辨率，留存窗口决定能回溯多远，两者都影响因果分析。

边界场景

向接收端单独注入时钟抖动并使接收 ECC 计数上升。若发送端供电波形仍平稳，应把该组错误保留为独立对照，单靠返回触发无法把故障归因到发送端电压。

条件推演

初始条件
教学 FIFO 深度为 8，按每拍一个整数样本。错误事件时刻 t10，停止指示在 t13 生效且 t13 不采。
处理结果
冻结后 FIFO 保留 t5–t12。事件前有 t5–t9 五个样本，事件时有 t10，事后有 t11–t12 两个样本。
结果解读
若回传延迟达到或超过滚动容量，同一策略会偏向事后，必要时增加深度或纠正触发基准。

  • 双 VCO 检测供电事件并提前降频

    电压波形可以用来动作，也可以留给故障诊断。US11736111B2 按局部供电事件直接暂时拉长周期。US11899061B2 用远端传输错误作为事件触发，保存发送端附近的电压历史供外部主机查看。错码给出了查找波形的时间锚点，单凭两者同时出现仍无法确认压降是错码的原因。
