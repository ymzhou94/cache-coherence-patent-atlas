按缺失率调整系统内存缓冲区的缓存预装顺序

Allocation of a buffer located in system memory into a cache memory

预装整个缓冲区时，能否通过改变地址访问顺序减少实际使用阶段的缓存缺失？

工作机制

缓冲区位于系统内存。结构上仍采用普通缓存的组相联映射和替换规则，预装的访问顺序会影响实际驻留内容。

先按非线性地址次序发出内存事务，让返回内容进入缓存。随后跟踪该缓冲区的访问缺失率，达到条件时改变下次使用的预装次序。

  1. 分配系统内存缓冲区

    确定待预装的地址范围。该区域继续由系统内存承载。

  2. 以非线性次序预装

    处理电路发出非顺序访问，返回时尝试驻留到缓存。

  3. 测量实际访问的缺失率

    只统计访问该缓冲区的事务，保持与预装阶段的计数口径一致。

  4. 调整下一次预装

    观察值达到阈值时改用另一地址次序，对后续缓冲区访问重新评估。

示例

初始条件
教学例中，同一缓冲区地址落入共享缓存的多个组。先测试一组非线性访问次序，再统计实际处理阶段的缺失率。
处理结果
如果观察值满足修改条件，下一轮改变发出顺序，比较该缓冲区的访问而非系统总命中率。
结果解读
比较必须固定缓冲区工作集、并发流量和统计窗口。该流程没有要求固定缓存容量或 PIPT 映射。

收益与代价

何时有效
实际访问之前可以预装高复用内容。对缓存冲突敏感的工作集可根据实际缺失率调整发出顺序。
代价和限制
预装增加内存流量与缓存占用，也可能逐出涉及其他工作负载的行。
验证指标
分别报告实际访问缺失率、预装读字节数、未成功驻留和其他流量的 P95 延迟。

权利要求与出处

独立权利要求为第 1、8、15 项。下方列出部分权利要求的中文释义。

权 1
程序介质权项包含非线性访问次序、跟踪缓冲区缺失率并据阈值修改顺序。
权 8
处理电路发出非线性次序的事务，缓存电路尝试驻留，后续使用前按缺失率调整。
权 15
装置权项明确系统内存、缓存与跟踪逻辑，各自负责缓冲区、驻留和反馈。
