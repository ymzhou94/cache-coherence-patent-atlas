部分有效缓存行的读补齐

Memory cache with partial cache line valid states

读到一条部分有效的缓存行时，怎样补齐空缺并保留缓存里的新值？

工程要点

回填逻辑用有效位掩码逐项选源，从内存数据补齐无效部分，并保留缓存中的本地修改。

成立条件
触发条件是读区段同时包含无效部分和已修改部分。内存返回不能覆盖已经有效的本地字段。
验证方法
给下层内存与本地修改填入可区分的值，重放跨有效和无效字的同一读取。逐字检查应答来源、缓存有效位及回填写使能。

工作机制

代理可以只改写缓存行的一部分。此时内存有缺失条目的值，缓存则保存某些位置的新值。整行都从内存复制会盖掉缓存中的修改。

控制器按有效位掩码合并本地数据和下层返回的数据。它只填无效条目，保留缓存中已修改的条目，再用合并后的值应答。

  1. 从 tag 识别部分有效状态

    读请求命中处于 partial 状态的区段。这个区段至少有一个无效部分，以及一个相对内存已修改的部分。

  2. 读取条目掩码

    掩码标出哪些位置要补齐、哪些位置可沿用缓存中的值。有效位表示本地条目可用，写回状态另行处理。

  3. 用下层数据补齐

    控制器向内存取回对应内容。下层返回值只填进掩码标出的无效位置，已有效且修改过的值继续保留。

  4. 返回合并后的值

    控制器用合并结果应答。需要写回时可另发下行请求，读合并的独立权项允许先返回结果。

权项与实施例约束

权利要求 1 允许部分修改、部分无效的区段边补齐边保留本地修改值。权利要求 7 在此基础上进一步要求把更新后的区段发送给内存控制器，两种权项的数据路径不同。

收益与开销

合并逻辑承担逐字段选择新旧数据的成本。若实施方式随后写回合并结果，额外流量出现在内存写侧。仅用下层读事务数会漏计这一部分。

边界场景

若返回侧以整个区段传输，而实施方式还请求回送合并结果，一次补齐可能同时消耗整段下层读和写带宽。这是具体总线粒度下的后果，权利要求没有规定传输宽度。

模型算例

初始条件
假设缓存行有四个条目，缓存里是 [9, 未知, 8, 未知]，有效位为 [1,0,1,0]。内存内容是 [7, 2, 6, 4]，第 0、2 项已在片内改为 9 和 8。
处理结果
内存结果到达后，控制器只填第 1、3 项，返回 [9, 2, 8, 4]。若把整段内存结果覆盖进来，第 0、2 项会退回 7 和 6。
结果解读
实际总线仍可能返回整段。片内只填两个位置，片外传输了多少字节还要看下层事务。

关联专利

  • 部分写缺失先建行，暂借 ECC 位标有效

    同一缺失片段和本地脏片段并存时，两件给出不同的读补齐顺序。US9218286B2 的权 14 将 ECC 位暂用作有效位置，先把有效片段写回再从内存读行。US11586552B2 的权 1 先读下层，仅用返回值补无效片段，保留本地修改后合并应答。

  • 部分写入、有效掩码与回送内存

    母案权 1 用部分有效状态处理读取，按掩码补无效片段，保住本地修改。继续申请权 1 处理对同一类状态的部分写入，将新值写入本地相应位置、向内存控制器发出这些位置的写请求，并更新掩码。两件合起来解释了后来一次读取为何能够区分可从内存补齐的片段和本地应保留的片段。

  • 匹配数据模式时跳过写入

    US11586552B2 对无效字从下层取数，合并时保留本地修改过的字。US20250013568A1 比较写入值与预设模式，跳过匹配值的数据写。部分有效掩码表示字的有效性，模式匹配信号表示写入值是否符合预设，验证时分别统计下层读与数据阵列写。
