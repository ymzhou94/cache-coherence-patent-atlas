按电池可用电量安排 AP 内存通道的启动训练

Memory channels calibration during boot wherein channels are calibrated in parallel based on identifer

有多个 LPDDR 通道待校准时，如何让电量充足的启动更快，同时限制低电量状态下的并行训练负载？

核心结论

启动代码读供电状态，选择一批内存通道，并向中央控制器写命令。广播中的 ID 与通道寄存器匹配时才执行校准。硬件收齐结果后向软件报告，软件重新读状态并选择下一批。

供电状态决定训练并行上限

0005 和 0020–0027 将有限电池供能的移动 SoC、CPU 执行 boot code、PMU 接口和低功耗 DDR 通道连入同一技术路径。独权控制的是启动训练并行度。

并行校准会叠加瞬时电流需求。说明书指出，电池供能不足时可能发生电压下跌（droop），导致训练结果不准或启动失败。图 1 标出 CPU 通过 PMU 接口读状态、内存控制器执行训练的分工。

该方法控制启动阶段的训练并行度。启动代码可依据电量和每通道训练负载选择批次大小。原文未披露任何产品的阈值、实测电压或训练时间。

同一条广播命令在每个通道本地划分是否执行

图 2 中，启动代码先给所选通道配置共同 ID，再写命令并置 run 位。中央控制器广播命令，通道比较本地 ID，匹配则启动训练。未选通道保持空闲并可回报 ID 不匹配。

图 3 分开各通道的 Ack 和结果。未选通道可较早返回。中央控制器收完全部通道状态后写合成结果并清除 run 位。权利要求 18 规定，只要有 error 则合成为 error，无错误则为 complete。

剩余待办通道按新的电量观测重新分批

图 4 绘出启动代码每轮更新待办通道清单的过程。若完成了一批仍有通道待训练，启动代码再次读取供电状态。后续电量可能更低，也可能因接入外部供电而上升。

测量时应区分一轮启动到最慢通道返回的耗时、全部所需训练完成时间和电池端最低电压。选择过多通道可能降低训练可靠性，选择过少则多次支付广播和等待开销。
