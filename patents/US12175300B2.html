GPU 为高优先级逻辑槽预留分布式硬件槽

Software control techniques for graphics hardware that supports logical slots and reservation of graphics hardware based on a priority threshold

当普通硬件槽被占满，高优先级图形工作怎样获得可分配的执行槽？

工程要点

GPU 控制器将工作绑定到逻辑槽，再按软件提供的优先级和门槛选择分布式硬件槽。未达到门槛的工作只能使用非预留槽。

成立条件
预留只影响硬件槽资格。高优先级工作仍需满足依赖、配置和可用执行资源等条件。
验证方法
固定槽位总数和高低优先级的提交序列，比较全部槽共享和保留一部分槽。分别测依赖就绪到槽分配的等待、预留槽闲置比例及低优先级吞吐量。

工作机制

GPU 使用逻辑槽表示提交工作，使用分布式硬件槽保存待运行工作和配置。软件把工作及优先级交给 GPU 控制电路。

GPU 按软件给出的优先级将工作绑定到逻辑槽。控制电路为满足阈值的逻辑槽保留一组硬件槽，未满足阈值的逻辑槽只能映射到普通槽。

  1. 接收软件定义的图形工作

    GPU 接收一组图形工作及其优先级，绑定一个逻辑槽。

  2. 等待分派的前置条件

    逻辑槽可等待依赖、配置数据或硬件槽。权 5 对这三种状态分别作了限定。

  3. 按优先级筛选硬件槽

    满足阈值的逻辑槽可申请预留槽，也可按规则使用普通槽。其他逻辑槽只参与普通槽分配。

  4. 将工作送入着色器

    分派到硬件槽后，该槽所在 GPU 子单元执行工作。若软件要求保留映射，工作完成后须等释放指示才能将其分配给另一个逻辑槽。

权项与实施例约束

权 2 允许按软件输入在一项工作完成后保留逻辑槽与硬件槽的映射，因此完成通知和可重新分配不是同一事件。权 5 另列依赖、配置和槽等待状态。

文中术语
逻辑槽
保存一组图形工作的标识、控制状态和分派信息。
分布式硬件槽
由特定 GPU 子单元实现，有局部工作队列和执行配置。
预留槽
只对达到优先级阈值的逻辑槽开放的硬件槽。

图解与对照

  • 低优先级占满通用槽时仍保留高优先级入口
  • 逻辑槽映射带有优先级门槛
  • 从逻辑槽等待到硬件槽分派
  • 按优先级判断硬件槽资格

收益与开销

高优先级提交时延分成依赖就绪、配置就绪、硬件槽分配和首条 shader 执行。预留直接减少硬件槽竞争，开销可见于通用槽等待和预留闲置。

边界场景

让高优先级工作的前置依赖一直晚于普通槽释放。若有无预留的首条执行时点相同，但普通工作吞吐下降，预留在该流量下没有缩短关键路径。

条件推演

初始条件
低优先级图形工作陆续占用非预留槽，后来有高优先级工作到达。
处理结果
低优先级工作不能填入预留槽，因此达到门槛的工作仍能参与其分配。依赖未满足时继续等待。
结果解读
以 GPU 命令提交到首个执行槽分配为延迟口径。开槽后还需观察实际 shader 启动。

关联专利

  • GPU 按缓存亲和性分派，并按组进度重分配

    US12175300B2 用软件优先级约束逻辑槽到硬件槽的映射，低优先级工作只能使用未预留槽。US12333339B2 在先有的软件映射上允许 GPU 硬件按分派进度重新分配工作组。对照时注意预留槽影响工作能否映射，重分派影响获准进入的工作交给哪组执行资源。

  • GPU 线程分两级分配到通道与执行流水线

    US12175300B2 在 GPU 工作映射阶段检查优先级门槛和硬件槽。US12190151B2 在译码前选择线程，在译码后根据目标流水线选择操作，并把执行流水线的背压反馈给第一级。两件使用的队列和控制量不同，验证时分别记录工作提交到槽映射、线程选择到操作发出的时延。
