GPU 逻辑槽映射给高优先级图形工作预留硬件槽

Software control techniques for graphics hardware that supports logical slots and reservation of graphics hardware based on a priority threshold

图形驱动提交的高优先级工作，怎样避免被低优先级队列占满所有硬件槽？

工作机制

GPU 使用逻辑槽表示提交工作，使用分布式硬件槽保存待运行工作和配置。软件把工作及优先级交给 GPU 控制电路。

控制器把工作绑定逻辑槽，选出预留硬件槽，把优先级低于门槛的逻辑槽只映射到非预留槽。

  1. 接收软件提交

    GPU 接收图形工作和软件指定的优先级。

  2. 分配逻辑槽

    逻辑槽保留控制状态。工作在依赖、配置或硬件槽尚未就绪时仍可等待。

  3. 限定可映射槽集合

    达到优先级门槛的工作可以使用预留槽。低于门槛的工作只进入非预留槽。

  4. 进入分布式执行

    工作映射后由对应子单元的 shader 执行。特定软件输入可要求完成后保留映射。

示例

初始条件
低优先级图形工作陆续占用非预留槽，后来有高优先级工作到达。
处理结果
低优先级工作不能填入预留槽，因此达到门槛的工作仍能参与其分配。依赖未满足时继续等待。
结果解读
以 GPU 命令提交到首个执行槽分配为延迟口径。开槽后还需观察实际 shader 启动。

工程图解与对照

  • 逻辑槽映射带有优先级门槛
  • 优先级检查位于依赖等待之后的硬件映射路径
  • 低优先级占满通用槽时仍保留高优先级入口
  • 按优先级判断硬件槽资格

收益与代价

何时有效
在 GPU 分配层隔离高低优先级工作对硬件槽的争用。
代价和限制
预留空间多会限制低优先级吞吐。依赖未满足或下游 shader 饱和时，硬件槽预留仍可能无法降低完成延迟。
验证指标
按优先级统计提交到槽分配的延迟，并跟踪预留槽空置时间和优先级分组吞吐量。

权利要求与出处

独立权利要求为第 1、11、17 项。下方列出部分权利要求的中文释义。

权 1
根据软件优先级配置保留槽，低于门槛的工作仅映射到未预留槽。
权 2
可按软件输入使一次工作完成后保留逻辑槽到硬件槽的映射。
权 5
可分别表示等待依赖、配置或硬件槽。
权 17
方法权利要求对优先级门槛和实际分发的约束。
