常开岛检测音频并保留仅内存唤醒路径

System on a chip with always-on component with powered-down configurations to process audio samples

工程要点

常开音频域在未识别到预设模式、采样缓冲达到阈值时，唤醒内存控制器和互连转存采样，CPU 保持断电。

成立条件
采集和模式检测可在常开域完成。局部缓冲还须能容纳内存路径恢复期间到达的采样。
验证方法
重放未命中模式的同一采样流，对照仅唤醒内存与一并唤醒 CPU。记录两电源域上电、第一笔写入、采样连续性和累计能量。

工作机制

常开岛可以独立于主 CPU 域和内存控制域工作。它将捕获、模式判定和存储溢出拆成不同动作，让达到容量阈值的流量可以只唤醒存储路径。

常开域的采集电路将音频样本写至本地存储器，本地处理器搜索预定模式。按权 1，若缓冲已到阈值且未检出模式，只恢复内存控制器与通信路径并转存，CPU 保持断电。

  1. AON 域捕获并暂存采样

    传感器捕获模块把音频采样写入岛内存储，此时 CPU 和控制外部内存的控制器都可以断电。

  2. 用岛内处理器匹配模式

    常开处理器查询岛内采样中的预定模式。捕获和识别发生在相同的独立域内。图 3 区分 capture 与 process 状态。

  3. 没有匹配但容量逼近时进入仅内存模式

    缓冲达到阈值且未检出模式时，常开岛使内存控制器与到它的通信通路上电，向第一内存拷贝采样，CPU 继续断电。

  4. 检测到目标时按另一条路径唤醒

    从属权项描述命中预定模式可以同时唤醒 CPU 与内存控制器。岛内没有任务时，捕获器和小处理器还可以单独门控。

权项与实施例约束

权 1、10 把到达缓冲阈值且无匹配列为内存路径上电条件，权 19 的无匹配条件限定后续样本转存。命中后同时唤醒 CPU 和内存控制器来自从属权。

文中术语
常开域（always-on component）
主 CPU 与内存控制域断电时仍可供电的部件，含采集电路、本地处理器和本地存储器。
缓冲水位阈值（threshold level）
本地存储器累积到指定样本量时触发后续判断。
仅内存访问状态（memory access state）
常开域供电，恢复内存控制器及必要互连，主 CPU 保持断电的运行状态。

收益与开销

分开计量常开域持续耗能、内存路径恢复、写入样本以及返回低功耗的能量。较大缓冲可以减少恢复次数，但水位余量仍要覆盖启动期间的数据增长。

边界场景

在固定平均采样速率下加入突发输入，测未检出条件下从触发水位到首笔主存写入的延迟。若期间发生缺样，检查恢复轨迹和缓冲剩余空间。

条件推演

初始条件
设岛内缓冲阈值为 32 个块。输入持续而本次未匹配关键词，另外一次输入则在阈值前匹配。
处理结果
持续无匹配到 32 时激活内存路径转存，CPU 没有因为转存而启动。匹配时可按从属项启动 CPU 与内存控制器。
结果解读
32 块是假设。实际容量应考虑采样速率、上电恢复时间以及在转存期间到达的新采样。

关联专利

  • 常开音频缓冲跨越内存控制器上电

    两件文献都允许在 CPU 和内存控制器关闭时缓存音频。US12117320B2 在未匹配声音模式且本地缓存达到阈值时，仅唤醒内存路径以转存。US12211506B2 的权利要求 1 针对模式命中后同时唤醒处理器与内存控制器，并在其可写之前保留匹配样本、之前的样本及随后收到的样本。

  • 用客户端状态约束共享内存的门控深度

    US12117320B2 权 1 要求缓冲达到水位阈值且未检出预定声音，才启动常开域通往内存控制器的路径。转存时 CPU 继续断电。US12609141B2 根据各客户端的运行参数设定内存资源的最低允许电源状态，并在该限制下执行时钟或电源门控。
