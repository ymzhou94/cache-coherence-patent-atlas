除法加乘减合为一次余数写回

Instruction fusion

核心结论

如果第二条指令读同一被除数、除数和商，并把余数写回商的目的寄存器，前端可将其合为一项余数运算。除法器生成的内部残余量经转换后直接写回。其他从属权项定义 ALU＋掩码、比较＋条件写入和常量生成配对。

从除法器残余量直接得到余数

原图 2 将指令配对置于取指译码和乱序 CPU 的 MDR、ROB、保留站及执行单元间。原图 11 说明 CPU 可执行 OS 和应用，并称其为 application processors。原图 13 给出手机和电池供电用例。

独权的普通序列先算商 q，再用被除数 n、除数 d 与 q 求 n−q×d，并覆盖 q 的目的寄存器。原图 3 的融合执行保留除法器内部残余量，由转换电路执行必要的合并、修正和移位。除法器不用先把商写入寄存器给独立乘减使用，从属权 3 进一步限定不做乘法。

配对要验证源版本和覆盖关系

原图 7 的二次检查分别验证除法指令和余数指令。后者必须读同一个商及两个原始操作数，同时覆盖商的目的。相同的操作码序列可能因目的不同、源被覆盖或中间消费者而不安全。译码可以附候选标志，MDR 再决定合并和派发。

掩码和条件写入各有独立的执行数据路径

ALU＋AND 的融合项在一个操作内应用受支持的掩码序列，再把筛后的值写回。比较＋条件写入把比较器结果直接接到 MUX，选择一个源值或一个常数。潜在收益来自缩短中间数据依赖和降低派发与发射压力。比较产生的架构可见状态仍要满足 ISA 对后续消费者的要求。

常量生成可以绕过普通执行发射

长常量的模式由译码识别，再由 MDR 专用电路组合两个片段，或者用页地址加上页内偏移。结果经侧写口到物理寄存器。MDR 的每周期侧写能力决定可处理组合的数量，扩展到更多常量片段可能加长组合路径。独权 1、13 均围绕余数；常量和其他整数模式是对应独权上的从属增加项。
