DRAM 自刷新后，AP 的 AON 处理器还能访问哪一级存储

Performance states in integrated circuit

CPU 关断后仍需处理常驻任务时，怎样逐级关闭 DRAM、内存控制器和 system cache 的访问能力？

  • 核心结论
  • CPU 关断后 AON 请求仍有独立路径
  • 关闭外存路径前要保证工作集已驻留
  • 超出 aperture 时先由电源管理恢复路径
  • 权利要求与出处
  • 关联专利

核心结论

不同深度的睡眠保留不同的访问路径。AON 可以先利用预装到 system cache 的工作集，随后把缓存切到 retention，由仍供电的 AOP 只从本地 SRAM 工作。

CPU 关断后 AON 请求仍有独立路径

原图 1A、3–5 和说明书 0078 给出电池供电移动 SoC 的 CPU complex、AON 两个处理器、system cache 和 DRAM 电源域。独权直接约束这些存储路径处于不同可用状态的条件。

图 1 区分 AON 本地存储、共享 system cache 和外部 DRAM。原图 3 给出 CPU 域已关断但 DRAM 路径仍开的情形。该状态下 AON 可正常访问内存，CPU cluster 保持关断。原图 1B 的内存控制器和缓存共用一个供电域。该变体无法同时关控制器又保留缓存读写。

图 2 对照两个更深档位。memory sleep 保持 system cache 可访问，同时关闭内存控制器并让 DRAM 自刷新。cache sleep 让共享缓存只保持数据。AOP 的本地 SRAM 可在后者继续工作。

关闭外存路径前要保证工作集已驻留

图 3 展开预装阶段。预取器指定给 AON 的 DRAM aperture，由内存控制器将区域数据填入 system cache。权利要求 8 允许填充完成确认携带状态而不把数据重新送回预取器。

等待其他电路停止访问，再完成预装，可避免进入自刷新后才发现数据未就绪。需要观测的延迟包括等待旧流量结束、装入工作集与进入自刷新的各阶段。

超出 aperture 时先由电源管理恢复路径

图 4 将缓存可访问和地址可访问分开。即使 system cache 保持供电，地址过滤仍可限制 AOP 直接访问的范围。区间外请求必须先获许可。权项 12 允许收到许可请求后先升档恢复内存。

进入更深档位会降低驻留功率，但唤醒时要恢复路径。可以改变常驻任务的工作集范围，测量预装流量、驻留能量及首次越界读到数据的延迟。
