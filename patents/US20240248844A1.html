宽 load 逐元素检查转发，跨缓存行另查访存顺序

Decoupling Atomicity from Operation Size

一条宽 load 读出的数据来自不同 store 或缓存行时，哪些数据可以组装，哪些情况需要重试或清除重取？

核心结论

LSU 逐个核对原子元素的字节来源。同一元素的所有字节必须来自同一合格来源，不同元素可以来自不同来源。对于跨缓存行的 load，还要核对各元素的可观察顺序。微码分解的 load 若因顺序违规被清除且已靠近重排序缓冲区队首，重译码时可附加顺序执行标记。

同一条 load 有操作宽度，也有原子性粒度

操作宽度是一个 load 微操作访问的总字节数。原子性粒度是实施的内存排序模型要求作为单个单位观察的字节数。原图 2 的寄存器对 load（LDP）可以访问 16 B，其中各 8 B 分别对应两个目的寄存器。向量 load 的原子性粒度可以是单个向量元素，也可包含相邻的多个元素，取决于实现。

LSU 先产生访问地址，再从 store 队列匹配同地址中在程序顺序上更老的 store，也访问数据缓存。图 1 将标定元素边界和核对来源分开。核对某个元素时，整组字节必须由一条 store 队列项或单个其他合格数据来源覆盖。不同元素可以分别由不同来源覆盖。若 load 的操作宽度恰好只含一个原子元素，原图 3 要求其所有字节均来自同一来源。

公开第 1、10 项明确规定操作宽度大于原子性粒度的逐元素检查。第 4、5、12–15 项分别限定寄存器、向量元素及相邻向量元素组合等粒度。说明书讨论 TSO 及可配置的排序模式，具体实现决定何时启用这些检查。

store 只覆盖半个元素时，为什么有数据也不能完成

图 2 用一个元素横跨 store 队列覆盖与数据缓存覆盖的例子。不论两路数据是否已经返回，来源条件仍不满足。LSU 阻止这次 load 完成，并保留可重试状态。原图 3 把禁止完成与正常转发分开；在这里尚未向依赖微操作正式提供结果。

说明书允许等匹配的较老 store 排出队列，也允许等更广的排空条件或周期重发。第 3 项写的是一个或多个目标 store 排出，第 11 项写的是 store 队列清空。排出之后需重新读和核对数据，普通缓存缺失及下级供给时间仍是原有访存路径的一部分。

若 load 已给出结果，随后侦测到跨缓存行顺序问题，则可清除该 load 及依赖操作。这属于图 5 的另一条恢复路径，图 2 描述的是完成之前的重试。

字节来自几种介质，和来自几个来源实例有什么区别

表 3 的来源列记录具体 store 队列项或缓存数据来源。两条 store 属于同一个队列，它们仍是两个来源。一个元素的字节分属两个不同的缓存行时，也需核实是否能按该粒度满足单源要求。较老 store 地址已匹配但数据未就绪属于数据依赖等待。

合格的原子元素并不要求操作级只有一个来源。允许逐元素独立供给，可以在某些多寄存器 load 中减少等待 store 排出或重试。若跨行或多微操作存在顺序约束，还须通过相应检查。

LDP 的两个元素何时能分别从两条数据路径取值

图 4 的上半部比较两条覆盖路径。较老 store 只写第一个 8 B，恰好覆盖元素 A。数据缓存完整提供第二个 8 B。对于来源检查，A 和 B 各自完整，所以可以向两个目的寄存器交付。

下半部中，较老 store 只覆盖元素 A 的前 4 B。即使缓存已经含 A 的余下 4 B 和完整的 B，A 仍不能作为一个原子元素完成。两组示例都设在同一缓存行内，故一次只考察元素来源，跨行观察顺序留给图 5。

跨行时两个元素都完整，为什么还可能被清除

原图 4 将第一个目的寄存器的元素置于缓存行 A，第二个置于下一缓存行。对于该实施例的排序模型，第一个元素应表现为与第二个同时读出，或在第二个之前。若先读的缓存行在整个 load 完成前被一致性失效，而第二个元素仍保有原缓存行数据，顺序可能无法继续保证。

图 5 将两次行数据返回、第一行发生失效、LSU 核对顺序与向重排序缓冲区（ROB）请求清除放在同一动态序列中。清除后可重新取指和执行。公开第 8、18 项对应跨缓存行的顺序检查。相同缓存行中的两个元素则可在此例作为同一次行访问提供。

什么时候让重取的子 load 按顺序发射

复杂 load 可以由译码／微码生成多个 load 微操作，每个微操作内部仍可有自己的原子元素。原图 6、7 允许这些微操作先乱序执行。侦测到顺序违规时，LSU 将需清除的 load 的 ROB 标签交给 ROB，ROB 清除此 load 与更年轻的微操作并恢复推测状态。

清除当时若指定 load 距队首不超过实现选定的 N 项，ROB 指示重取的同一条 load 按顺序执行。译码为这条指令生成的多个 load 微操作附上顺序执行标记。说明书举例，保留站只在操作成为站内最老时允许其发射。距队首较远仍会清除和重取，重取后不由此条件强制顺序。

第 9、17 项给出此恢复策略，第 19 项规定给微操作贴顺序执行标记，第 20 项允许编程门槛。ROB 队首邻近性是触发顺序重发的启发式，它与原子元素的宽度或缓存命中延迟采用不同的观测位置。
