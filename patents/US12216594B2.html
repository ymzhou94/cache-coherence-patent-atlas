双 rank 读轮次按请求数分配槽位并按 QoS 切换

Read arbiter circuit with dual memory rank support

两个 DRAM rank 共用数据总线时，读轮次如何兼顾槽位分配和请求时限？

工作机制

同一个读轮次可服务两个 rank。过于频繁的 rank 切换消耗总线时序裕量，只按一种请求来源服务又可能延长另一侧等待。

控制器按两个 rank 的待处理读请求数分配本轮的读槽位，并用服务质量约束确定本轮允许的 rank 切换次数，然后执行已分配的读。

  1. 按目标 rank 对请求分类

    两个请求子集分别对应两个共用物理总线的 rank。

  2. 在读轮次起点分配槽位

    用两侧待处理数量为有限的读槽位分配额度。

  3. 确定 rank 切换次数

    按一项或多项 QoS 要求决定在本轮切换多少次。

  4. 执行分配结果

    仲裁器按得到的槽位和切换约束发出读请求。

示例

初始条件
教学设定中读轮次最多允许六次读，rank 0 有四个等待请求，rank 1 有两个，其中一个具有时限。
处理结果
总槽位分配仍参考 4 与 2 的待处理量。时限可影响何时以及允许几次切到 rank 1。
结果解读
例子未指定实际槽位计算公式。比较方案时保留相同的最大槽位与 DRAM 时序。

工程图解与对照

  • 两个 rank 共用总线，由读仲裁器分配槽位
  • 先确定槽位和切换，再执行本轮读
  • 双 rank 读仲裁的三项输入
  • 评价尾延迟时保留两侧统计

收益与代价

何时有效
槽位不必在两个 rank 间固定对半。控制器可依据 QoS 调整服务交错程度。
代价和限制
rank 切换仍有物理时序开销。过少的切换可能增加另一 rank 请求等待。
验证指标
按 rank 记录分配槽位、实际服务数、切换次数，及达到各 QoS 阈值的读请求比例。
