同一次 trace 读取同时准备尾部方向与后一组地址

普通 NFP 可给出当前取指组后的地址，trace NFP 可给出整个 trace 后的地址。两条地址预测与尾部方向的共享表预测用途不同。

  1. 取指 PC 同时供给多个查找路径普通 NFP 使用当前组上下文；trace NFP 指向更远的 trace 结束位置。两者可按不同表实现。
  2. 共享预测器发出 trace 最末 CTI 的方向尾部 CTI 与普通组的预测共享 TAGE 数据资源。地址预测可由 trace NFP 独立提供。
  3. 命中 trace 时仲裁选择跨越多组的地址以结束位置为基准的下一 PC 避免逐组循环预测。错选或 trace 未命中时仍应回到当前取指的适当预测。
  4. 可将压缩的历史更新带到下一次取指原图 6 中，预哈希历史 token 减少把多个内部控制转移逐个更新的组合步骤。该点属于说明书实施例。
