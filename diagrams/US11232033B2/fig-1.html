软件配额配置与硬件访存请求走两条路径

在同一架构图上对齐驱动的带宽估计、控制器的 DSID 映射及缓存分配。

  1. 软件策略计算 由 memory cache 驱动估算调配前后的下层带宽。
  2. 向控制器提交配额与优先级 各 DSID 可以映射到同组。
  3. 硬件实发请求 作用在本次请求的分配和替换选择。
  4. 运行时反馈 使用量和数据流变化用于计算后续策略。
