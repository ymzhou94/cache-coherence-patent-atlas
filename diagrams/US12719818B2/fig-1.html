CPU 的 DRAM 访问与非 DRAM 事务各有路径

内存控制器接到系统内存。CPU 同时可把非 DRAM 命令交给 NSM gateway 跨到 I/O 网络。

  1. DRAM 读写走正常内存路径CPU 和 I/O 可经各自网络访问接到 DRAM 的控制器，无需让 DRAM 数据经过 gateway。
  2. 非 DRAM 事务在 gateway 内集中定向写目标设备寄存器，或读写内存控制器的配置寄存器，都可能属于此类，因为它们不访问 DRAM 存储阵列。
  3. I/O 代理无需接到 CPU 网络两端 NI 可以只为 gateway 保留路由相关存储，由 gateway 承担跨网络转发。
