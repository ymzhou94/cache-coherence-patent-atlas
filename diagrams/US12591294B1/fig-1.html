CPU 关断后仍有三层可分开供电的存储路径

AP 保留 AON 域。AOP 可以从本地 SRAM 运行，也可在允许的档位经 system cache 或内存控制器访问外部 DRAM。

  1. 访问 system cache 的 AOP这个 AOP 的工作集可以被预装到 system cache。缓存睡眠时可关断该处理器。
  2. AON 本地 SRAM另一 AOP 在更深睡眠里仍访问这块本地存储。
  3. system cache缓存和内存控制器使用各自的电源域。
  4. 外部 DRAMCPU sleep 可通过内存控制器访问 DRAM。memory sleep 中 DRAM 自刷新，不能进行普通访存。
