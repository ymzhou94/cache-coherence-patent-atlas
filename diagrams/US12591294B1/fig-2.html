每级睡眠关闭的其实是不同的访问能力

CPU sleep 保留完整内存路径。进入 memory sleep 后只允许访问保留的 cache 和本地存储。cache sleep 中 system cache 转入 retention。

  1. 三种睡眠状态横轴按可以关闭的路径排列。原说明书还允许从部分睡眠档位直接唤醒 CPU。
  2. 普通 DRAM 访问memory sleep 与 cache sleep 的 DRAM 都可保持自刷新。
  3. system cache 的可访问区间cache sleep 时降到只能保持数据的供电状态，恢复后可以读取保留内容。
  4. AON 本地 SRAM即使 cache 保持而不提供读写，AON 本地路径仍可用。
