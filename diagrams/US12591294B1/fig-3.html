内存控制器断电前把 AON 工作集移入缓存

预取器选定已给 AON 分配的连续区域。内存控制器把数据写到 system cache，并能只回送完成回应。

  1. 先结束旧访存权项 6 增加等待其他电路停止向内存发请求的条件。
  2. 发出连续区域的预填充请求连续地址空间在进入 memory sleep 前复制到 system cache。
  3. 预取完成应答权项 8 的响应确认已经装入缓存而不包含该区域数据。
  4. 允许 DRAM 自刷新只有预填充物理访问仍能完成的时候才能发出这些数据请求。
