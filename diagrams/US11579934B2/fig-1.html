性能推荐与热控限制分别抵达调度器和电源管理器

核型建议和可调度核掩码交给 OS 调度器。电源管理器接收各 CPU cluster 的 DVFS 运行点，硬件发射节流读取供电电流。

  1. 线程组观测线程组观测模块按线程组标识汇总样本。WIO 或 IPC 改变归属后，按新归属统计。
  2. 核型建议核型建议用于选择目标运行队列。推荐运行点从 CLPC 的另一条路径送往控制量限制器。
  3. 控制量限制器快速裸片温度回路按核型提供上限，其他控制回路约束整个处理器复合体；功率映射再将控制量上限转换为各 cluster 允许的 DVFS 运行点。
  4. 可调度核掩码可调度核掩码变化约束新的线程派发。清位后，正执行的线程仍可运行到后续调度事件。
  5. 各 cluster DVFS 运行点原图 3 将送给电源管理器的结果标为 E-core 与 P-core DVFS states，由电源管理器按各 CPU cluster 实际落地设置。
  6. 硬件指令发射节流为抑制稳压器至处理器复合体供电网络的 droop，硬件检测到电流超限后可阻止部分指令或微操作发射。
  7. 发射节流率控制器按采样窗内的阻塞发射槽位数除以处理器复合体周期数。控制器依据目标节流率生成控制量上限，通过功率映射压低允许的 DVFS 运行点。
