物理页散列同时服务全局筛选和逐 trace 走查

指令缓存维护按 PPN 合并。L2 写入记录所有取指组的 PPN 散列，过滤器命中后才访问每条 trace 的旁路记录。

  1. 指令缓存失效合并缓冲 同一物理页的多条指令缓存行失效可合并成一条 PPN 送去散列。原文另给合并缓冲溢出时清空 L2 的路径。
  2. L2 trace 条目写入 记录的范围覆盖 trace 内每个取指组。入口只代表其中一个组的地址。
  3. 物理页号散列 写入和维护查询使用同一个物理页散列规则，让二者在过滤器和走查中可比。
  4. 指令缓存失效过滤器 写入置位，维护查询若未命中可免走查。过滤器命中可能只反映散列碰撞。
  5. 旁路 PPN 散列 SRAM 旁路 SRAM 按 L2 条目保存各组的 PPN 散列，适用于主标签存虚拟地址的组织。
  6. L2 trace cache 走查 逐条读取有效 L2 trace 对应的散列，失效匹配项，用其余有效项重建过滤器。
