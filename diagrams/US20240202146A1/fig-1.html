跨越控制器与 DRAM 边界的 CMD 和 DATA 路径

上游仲裁和 bank 调度都发生在控制器。SYNC 通过 CMD 进入 DRAM 后，由 DRAM 控制 W CK。

  1. 内存 cache 缺失在含有 memory cache 的实施例中送相应 MCU。
  2. MCU 通道调度器排列 ACT、RD、WR、SYNC，且每个 CMD 周期只装一条命令。
  3. CMD 命令路径使用 C CK 计时。
  4. DATA 数据路径图画读返回，写数据方向相反；W CK 启动由 SYNC 控制。
