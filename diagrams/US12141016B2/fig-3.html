定时器须把复电、恢复配置与 DRAM 退出纳入同一截止时间

CPU 预先准备在内存中的帧。后续帧的常规定时唤醒只恢复取帧链路，只有剩余预渲染内容接近门槛时才需要 CPU 重新补充。

  1. 把通用计算移到断电前做CPU 和可选 GPU 准备帧，写入内存。显示侧工作不在每帧都依赖 CPU 上电。
  2. 定时器需要早于显示目标唤醒链路延迟由电源恢复、配置、退出 self-refresh、取帧和帧处理组成。
  3. 唤醒对象是取帧子系统PMGR／PMU 恢复显示、内存控制器及相关互连段，恢复 DRAM 访问。图 2 展示这些电路的供电状态。
  4. 分清两种唤醒延迟取帧唤醒结束于帧可按时提交。补充帧才需要等待 CPU 域和 OS 运行。
