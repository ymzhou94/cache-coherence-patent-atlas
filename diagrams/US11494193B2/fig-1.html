卸载开始与结果返回是两个控制采样边界

CPU 提交协处理任务时，CLPC 保存该线程组的 CPU control effort。结果可交付时，CLPC 用保存值派生 CPU 的起始控制量。

  1. 提交协处理工作同一线程组的处理器和协处理器各有对应控制量。提交本身并不说明 CPU 何时被调度。
  2. 保存 CPU control effort记录卸载边界上的 CPU 控制量。工作卸载期间 CLPC 普通反馈仍可改变 CPU 当前值。
  3. 协处理结果就绪驱动通知结束；工作结果送回处理器时进入独权规定的重置边界。
  4. 重新设置 CPU 控制初值界面能选择从保存值、或从其派生量起步，不用等待普通反馈从低值逐步上调。
