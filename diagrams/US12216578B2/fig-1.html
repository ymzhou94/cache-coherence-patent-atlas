请求数据分散存放，两级 token 描述顺序

请求地址决定处理流水线，空余条目决定那条流水线内的缓冲。对于严格有序请求，把两次选择分别写入两个顺序 FIFO。

  1. 先按地址选择处理流水线 银行选择电路查设备地址所在区域。地址到管线的映射不提供请求到达顺序。
  2. 再选有空间的请求缓冲 所选流水线可以有两个缓冲。控制器可比较空余条目，再写入完整请求。
  3. 二级 token 记录流水线 在该处理器的严格有序序列中，按请求到达顺序保存被选流水线。二级 FIFO 不存完整请求数据。
  4. 一级 token 记录流水线内的缓冲 对严格请求只在已选流水线对应 FIFO 记录缓冲。其他处理器可以有自己的两级 token 系统。
