迁移期间 BIU 过载标记与单线程标记各跟踪什么

历史过载记录属于源 CPU cluster。迁移移动线程 2.C 及其线程标记，目标 BIU 的状态仍由自身观测决定。

  1. 源 CPU cluster 原图 4B 保存的是线程记录。源 CPU cluster 的过载标记位于性能控制器对共享资源的历史观测中，不随线程迁移。
  2. 2.C 的 BIU 标记 线程 2.C 的标记在性能控制器报告归因成功后置位。另一路潜在的清除由性能控制器发出通知。
  3. 同组其他线程 同一线程组中的其他线程各有独立记录，本例不把 2.C 的标记复制给它们。
  4. 2.C 执行位置 原图 3C 的示例把 2.C 从 P-core cluster 3 迁到 P-core cluster 2。横轴是说明书事件次序，迁移和清除无指定间隔。
