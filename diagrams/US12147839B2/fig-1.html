LLC 缺失路径与 BIU 过载判定

请求走上面的硬件路径。下方的两项计数用于形成过载标记，该标记描述 CPU cluster 的共享资源。

  1. CPU cluster 的 LLC 末级缓存（LLC）对本 CPU cluster 的核心共享。说明书允许它是 L2；外层的系统缓存位于互连另一侧。
  2. BIU 请求队列 LLC 缺失请求进入 BIU 请求队列，再交给互连。有请求到达且队列满时，会增加请求等待。
  3. 满周期占比 满周期数除以采样窗内总 BIU 周期数，得到占比。两个计数均以 BIU 时钟域为观测基准。
  4. 比较可调阈值 说明书举例低通滤波对瞬时抖动进行平滑，再与可调阈值比较。
  5. BIU 过载标记 标记描述已经观察到的 BIU 过载，调度回调还要加入当前线程的资源使用数据。
