线程 2.C 转向目标 BIU，同组其他线程继续使用源端

迁移前共享一条接口。迁移后各自通过本地 LLC 和 BIU 发起外向请求。

  1. 线程 2.C 原图 3C 的 P-core cluster 3 运行线程 2.C，访问缺失可经过源端本地 BIU。
  2. 源端 BIU 请求队列 该阶段线程 2.C 和同组其他线程可共享源端 BIU，过载标记对应这条共享接口。
  3. 线程 2.C 调度器把 2.C 放到 P-core cluster 2。线程开始在目标执行后，访存使用目标 CPU cluster 的本地资源。
  4. 同组其他线程 同组其余线程可以继续使用原 CPU cluster，迁移的决策对象是带标记的线程。
