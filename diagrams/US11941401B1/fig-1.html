RAS 确定返回地址，按返回地址另取续段提示

函数的 RET 可能从多个 call site 返回。返回预测表按 RAS 给出的续段地址保存已有 fetch width 和 branch predictor bank，而不是按 RET 的 PC 记唯一一组参数。

  1. 地址来自 call 后继指令call 时 push 后继地址，匹配 return 取栈顶。同一函数从不同 call site 调用可得到不同续段。
  2. 参数表按已见的返回地址索引这里取到的是续段的宽度、预测表 bank 等元数据。与 RAS 关联时还可把参数随地址一起入栈。
  3. 返回请求带三个不同字段续段起点决定 I-cache 地址；宽度决定结束位置；bank 字段引导条件分支预测查询。
  4. 续段仍由 I-cache 提供本方案的返回预测电路给元数据。专利 US12373215B2 的 RFS 另存指令内容并可绕过相应 I-cache 请求。
