从第一次返回训练，到两种命中消费时机

首次 call 检查续段预测表。缺项时先保留返回地址，等对应 return 之后根据取得的续段建表。命中后，既可在 call 就查参数入栈，也可在 return pop 地址后查询。

  1. 初次 call 的查表 miss 说明续段参数未知仍正常 push 返回地址，识别 RET 后可用地址发出全宽请求。
  2. 初次 return 的实际续段用于确定宽度和 bankI-cache 的全宽结果和分支预测器的 bank 状态为建项提供数据。
  3. 后续 call 可以先读取元数据在 call 侧把地址与参数一起 push，把参数表访问移出 return 的依赖链。
  4. 也可在后续 return 时用刚 pop 的地址查表RAS 项更窄，但 return 的地址路径之后还要串行访问返回预测表。
