全局功率分配与 AP 各域的执行路径

顶层电路为 CPU cluster、GPU、互连等 AP 部件分配功率。各域的速率控制和功耗控制电路在本地选择并执行相应节流动作。

  1. 全局功率分配器同一预算在多个独立电源域之间分配，来自上级供电能力及可编程策略。
  2. CPU cluster 的速率控制同时接收分配值和本地 DPE 估计。对应 GPU、互连和内存控制器也可部署各自控制路径。
  3. CPU cluster 的执行动作权项 18 举例可减少可用核心、降低 issue rate 或插入流水线气泡。
  4. GPU 的执行动作独权要求至少两种部件的功耗管理机制不同。各域动作由本地电路决定。
