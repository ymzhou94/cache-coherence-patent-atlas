跨裸片投递先完成所有 Soft 尝试，再启动 Hard

把远端中断上报、本地与远端的 Soft 与 Hard 放在同一时序中，显示何时产生跨裸片往返、何时才可能给处理器上电。

  1. 上报远端中断来源远端从中断控制器可以上报本裸片的中断来源。主控制器接管投递；来源在哪颗裸片不规定中断由哪个处理器接收。
  2. 远端 B Soft本地 Soft 返回 Nack 后，主控制器保持 Soft 模式向远端 B 发请求；B 的从中断控制器在本裸片各 CPU cluster 组织尝试，并向主控制器汇总应答。
  3. 本地 Hard本地与远端 Soft 候选全部拒绝后才重新从本地开始 Hard；此轮可以把原先断电的处理器纳入尝试。
  4. B 汇总 Ack本地 Hard 返回 Nack 后，主控制器将同轮请求送给远端 B。此处 B 返回 Ack，余下远端无需接到本次 Hard 请求。
