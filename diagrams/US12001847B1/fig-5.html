推测地址通过旁路送给更年轻 load，旧寄存器值如何被挡住

当中间地址可用时，年轻 load 可继续；旁路结果失效后，记分牌阻止读旧寄存器值。

  1. 更早的 load A 更早的 A 仍在等待缺失数据，体系结构结果保持程序顺序。
  2. 独立运算 B 独立的运算 B 能先求出地址，原文允许该中间结果被更年轻指令临时使用。
  3. 推测旁路网络 旁路网络暂存中间值，可送至其他执行单元或 LSU。
  4. 寄存器记分牌 标记目标寄存器仍含旧值，旁路失效时不能回退读取这个旧值。
  5. load C 检查地址 先检查旁路是否有值，再依据记分牌排除旧寄存器值。
  6. 年轻 load C 当旁路地址有效，年轻 load C 可以从该地址发请求。
  7. 停止继续推测 若旁路查不到且寄存器已标旧，当前 C 的地址无法确定，停在推测边界。
