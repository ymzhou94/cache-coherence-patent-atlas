I/O agent 何时把部分写与未覆盖旧数据合并

分开看原来缓存行、新写字节与合并后数据。合并之前仍可响应针对原行的 snoop。

  1. 已取回数据缓存 独占写访问权请求返回的原行可单独暂存，并保持未修改版本。
  2. 新写入数据缓存 待处理外设写的数据先留在这里，等依赖解析。
  3. I/O agent 控制器 写请求排到队首且有效权限可用时，从两个缓存读取相应字节。
  4. 合并数据缓存 本次写只替换覆盖范围，未覆盖部分保留原行字节。
