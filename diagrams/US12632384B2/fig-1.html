外设的独占读访问由 I/O agent 和内存控制器协作

外设收发自己的事务，I/O agent 与内存控制器通过一致性消息决定谁可以缓存该行。

  1. 独占读访问权请求 I/O agent 将目标地址的权限请求发给管理本行的内存控制器。
  2. 目录命中时发 snoop 控制器用目录匹配仍持有有效副本的缓存代理并发出请求。
  3. 响应与数据 本例采用 snoop back，必要的数据由被 snoop 方返回内存控制器。
  4. 内存返回数据 若相关缓存没有所需数据，内存控制器可从所管辖的内存取得该行。
  5. 外设看到的完成响应 设备只收到 I/O agent 发出的事务完成，不参与一致性协议。
