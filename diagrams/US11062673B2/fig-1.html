内存控制器四路吞吐量怎样形成 CPU 运行点请求

四组采样分别计算偏差并更新历史状态。功率管理器读取取大结果，执行 CPU 运行点调整。

  1. 内存控制器 采样位置为内存控制器。此处分别观测通过控制器的 CPU 和闪存入向、出向流量。
  2. 闪存出向比较器 例如闪存出向吞吐量与这一方向的阈值比较，产生本路吞吐量偏差。其他通道各自使用阈值。
  3. CPU 入向积分 积分器保留该路历史偏差。当前吞吐量最大的通道和当前积分控制量最大的通道可以不同。
  4. 控制量选择器 图示实施例对四路控制量取大。独立权利要求描述至少两路的各自积分。
  5. 运行点 功率管理器根据控制量配置 CPU 运行。请求值到电压、频率的映射是单独的一步。
