三条互连按事务角色接入同一组内存控制器

CPU 一致性访问、CPU PIO、外设与 GPU 在不同网络上发出，在控制器可能重新竞争共享资源。

  1. CPU 一致性内存事务在示例中，cluster 经 LLC 向 CPU 网络发出一致性访问。
  2. CPU 访问设备空间同一 CPU cluster 可按事务类型选择 I/O 网络。
  3. relaxed-order 网络GPU 流量在该示例使用单独网络，连到内存控制器。
  4. 内存控制器每个控制器服务对应地址范围，可有各自缓存及一致性目录。
