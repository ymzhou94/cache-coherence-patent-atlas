CPU 与 GPU 用不同的交换节点，能直达同一个内存控制器

CPU cluster、GPU、I/O 可以使用不同的片上网络。原图 5 用不同交换节点和物理连线送到共享内存控制器。隔离观察点要分清网络段和共同控制器。

  1. CPU cluster 通过 LLC 发起访存事务 原文写 cluster 含两个或更多 CPU 核和给定 LLC。CPU 网络可以承担一致性内存流量。
  2. GPU 有自己的物理网 原图 8 采用 mesh，和 CPU 的交换节点、链路分开。权利要求 10 限定环与 mesh，权利要求 11 另限定 GPU 网络为非一致性。
  3. I/O 是第三个例子 某些外设可以经 I/O 网访问控制器，某些视频部件另有通往 relaxed-order 网的接口。图里只画一种代表性 I/O 通路。
  4. 各网络直接连接的共享终点 原文没有要求把 CPU 事务先转发到 GPU 网再访问同一内存控制器。内存控制器处仍可能发生下游仲裁和带宽竞争。
  5. 内存介质是另一项共享资源 测隔离时，可在两张网的入端和内存控制器分别记录排队，从而确定饱和发生在哪段。
