先按事务类型选网络，再在该网选 virtual channel

同一个 CPU cluster 可以同时接入 CPU 与 I/O 网。内存访问和 PIO 走不同硬件网，LLT、bulk、RT、VCP 是在各网络内进一步选择的虚拟通道。

  1. 同一 CPU cluster 的两类事务分流 一致性内存流量走 CPU 网，设备空间 PIO 可走 I/O 网。图示的是说明书的路由例。
  2. LLT 与 bulk 共享所选物理网络 原文允许把部分较急或限制数量的缺失送 LLT，其余走 bulk。选了 LLT 并不改变物理网。
  3. 非内存流量与实时流量有不同虚拟通道选项 VCP 可分离非内存事务，RT 适用于有延迟及带宽要求的实时访问。原图 12 在常规实施例将两者放在 I/O 网。
  4. GPU 网络仍可提供低延迟通道 GPU 流量走 relaxed-order 网，可按紧急程度选 LLT 或 bulk。该网可省去一致性 snoop 所需的虚拟通道。
