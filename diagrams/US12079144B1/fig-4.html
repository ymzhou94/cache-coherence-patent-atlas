C 在队首时能发，排在 W1 后面时仍会阻塞

只改 C 和 W1 的 FIFO 位置，观察同一个忙周期的空闲命令槽能否被使用。

  1. C 在同一 FIFO 的后项 当前周期资格判定只看 W1，C 即使不需要数据也不能越过。
  2. 命令周期空闲 如果没有其他合资格队首，数据继续传、命令总线空一拍。
  3. C 位于另一 FIFO 队首 C 独立参与资格选择。
  4. 在同一周期发 C 命令总线发送 C，数据总线仍传 W0 的尾段。
