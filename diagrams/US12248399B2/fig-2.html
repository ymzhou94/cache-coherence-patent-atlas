块驻留状态与待取数状态是两组位

例中按 [D C B A] 排列块。C 已有有效数据。A、B、D 缺失时，下一笔请求掩码为 1011。

  1. 块有效位来自数据阵列C 已有数据，valid mask 为 0100。硬件查找仍只读取本次请求指向的块。
  2. tag 的 fetch pending 表示整组还有未完成取数组级位用于追踪占用。A、B、D 各自的未完成状态由 scoreboard 单独记录。
  3. mask 选出非连续块相同 tag 的 C 夹在 B 和 D 中间。由于 C 没有新需求，电路保留 C 的驻留状态，取数操作只指定 A、B、D。
