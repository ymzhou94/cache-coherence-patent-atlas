L2 用扩展标志和指针连接长 trace 的两个物理分段

普通条目可以只从主阵列读取。长条目先解出尾段索引，再将前段与尾段拼成 fast array 的一个宽条目。

  1. L2 主阵列主条目包含指令前段、扩展标志与尾段指针。短条目只使用主阵列保存的指令。
  2. 溢出存储扩展标志开启时，根据主条目指针读取对应尾段。溢出存储满时说明书允许缩短条目或逐出一个溢出项。
  3. 宽条目组装读取相应尾段后恢复顺序。fast array 可原生容纳完整宽条目，实施例中无需再追逐溢出指针。
  4. 消费宽条目前端缓冲会按可容纳宽度把这组指令写入多个条目。扩展标志为长时保持 fast array 供给路径。
