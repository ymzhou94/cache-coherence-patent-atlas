短 trace 可以进入 L1，长 trace 由 fast array 直接供给

前端近端 L1 只需容纳最多 N 条指令。fast array 能容纳 N＋M 条指令，长 trace 无需穿过 L1 才能进入指令缓冲。

  1. 较远的 L2 trace cacheL2 容量可以更大，能够保存更长的 trace。较远的数据到达前端需要更长时间，因而可提前预取。
  2. 近端预取缓冲fast array 支持更宽的取指组。已有对应且匹配的条目时，可以从该位置直接为前端供给。
  3. 短 trace 可以晋升带扩展标志的长条目不晋升到窄 L1。短条目可按使用情况晋升。
  4. 前端指令缓冲某些实施例让普通缓存行或 L1 trace 各占一个条目，长 trace 同时使用多个条目。
