长 trace 需要在前端需求到来前完成预取

lookahead 先发起查找。L2 条目经组装进入 fast array，到需求命中时再为前端提供完整数据。

  1. 有效预取来自一条预测路径签名 lookahead 以取指路径地址历史预判将要执行的 trace。说明书的训练例包括 L1 缺失而 L2 命中。
  2. 合并前段和尾段L2 长条目需按扩展标志和指针取尾段。缓冲项组装完成后可匹配取指需求。
  3. 需求到达有效预取项准备完毕且当前需求的地址匹配时，才会提供此前取得的数据。
  4. 整个长 trace 直接供给本例长条目从 fast array 提供，避免把它载入容量为 N 的近端 L1。迟到和取错的边界见表 4。
