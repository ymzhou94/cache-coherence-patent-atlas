互连先按设备路由，缓存控制再按 PA 查行

把地址选择动作逐个对应到实际字段消费点，区分协处理器 ID、缓存 ID 与 PA。

  1. 形成远程失效命令包 命令由主处理器执行远程失效指令后生成。地址与粒度可来自指令。
  2. 按协处理器 ID 路由 互连将命令送指定协处理器。
  3. 命令处理器 目标内可用缓存 ID 选择要执行的缓存层级，并用粒度决定单行或范围。
  4. PA 对应的 tag 缓存控制器对目标缓存执行地址匹配。
