从路径签名发出查读，再用两类前端事件训练

路径前段的取指 PC 能触发后续 trace 的 L2 查读；命中与置信度负责准入，指令预取和目标预取由两类事件分别训练。

  1. 取指 PC 当前取指 PC 到达时，目标 trace 所在的动态路径还未被需求取指访问。
  2. 路径签名生成 签名可由单个地址构成，也可融合当前地址和历史签名。异或是第 3 项所述实施方式。
  3. 前视签名表 表项保存预取候选。说明书的实施例在命中、训练完成且置信度足够时才预取。
  4. L2 trace cache 预测命中后发起 L2 trace cache 查读；这里的 L2 不参与 CPU 数据缓存访问。
  5. trace 指令训练 L1 缺失且 L2 命中，说明这条已缓存 trace 有机会靠提前发出而及时到达。
  6. 后继目标训练 L1 已命中但后继目标预测错误，说明指令已有供给，仍可训练后继目标预取。
  7. 预取训练流水线 用执行或取指结果按签名更新各类置信度，避免把指令可用和地址正确当成同一件事。
