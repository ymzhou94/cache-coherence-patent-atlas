线程组需求映射到同核型 CPU cluster 的性能岛

配置三个不同控制量区间。控制器先匹配区间，再选择岛内首选 CPU cluster 并建议给 OS。

  1. 执行样本调度器可提供线程组执行观测。性能控制器按组选取满足目标的控制量。
  2. 性能岛映射性能岛按控制量范围配置。图中为原图 4 允许四个 P-core cluster 的同核型示例。
  3. 性能岛 1岛 1 的 0.4 ≤ 控制量 < 0.6，E 组 0.5 对应该岛。
  4. 性能岛 2岛 2 覆盖不低于 0.6 的控制量，D 组 0.8 对应该岛。
  5. 首选 CPU cluster岛的选择与岛内的首选 CPU cluster 是两步。OS 调度器接收建议后安排实际执行。
  6. 外溢边权重调度器还可以反向提供边权重，作为负载外溢的控制输入。
