带宽与延迟的运行点请求在哪里合并

CPU 或 GPU 的请求完成信号形成两路反馈。性能状态控制电路综合带宽和延迟请求，控制的是被观测的缓存或内存层级。

  1. CPU 或 GPU发送访存请求并提供各自的指标。共享缓存允许为不同客户端保存单独的延迟统计。
  2. 延迟控制器可以只跟踪读事务、高优先级事务或指定虚通道。
  3. 延迟运行点请求在低并发且高延迟时，该路径可独立请求升档。
  4. 性能状态控制电路示例中取两个电路建议的较高运行点。说明书还披露加权或逻辑合并。
  5. 被控制的缓存层级原图 8 的缓存／内存控制器可按 CPU、GPU 或两者的延迟控制 memory cache。
