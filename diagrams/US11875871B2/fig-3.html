响应汇总后，中央控制器才清除 run 位

未匹配通道无需训练，可较早回报。匹配通道保持 Ack 到训练结束，中央控制器收齐后决定合成响应。

  1. 未选中的通道报告 ID mismatch这是选择结果。为未匹配通道提供独立状态可让中央控制器知道该通道已处理命令。
  2. 所选通道完成后返回各自的 Rsp一个 Ack 下降后可采集该通道结果。所有通道处理完才可形成最终 Resp。
  3. 软件等待 run 位变为 0在权利要求 18 的规则下，有任一通道报 error 则合成 error。没有 error 则为 complete。
