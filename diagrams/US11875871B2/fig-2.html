广播命令相同，只有匹配 ID 的通道开始训练

配置每个通道自身的 ID 寄存器。中央控制电路用广播统一启动本轮，通道自己比较并回报。

  1. 命令寄存器保存 CMD、ID、Resp、R启动代码先写所选通道 ID，再写命令中的目标 ID，置 R 启动。
  2. ID 匹配后由通道本地硬件实施中央电路不会为每个命中的通道重发整条训练命令。
  3. ID 不匹配只回不匹配状态普通命令的其他通道可保持空闲。说明书还提供一个全通道通配值的例子。
